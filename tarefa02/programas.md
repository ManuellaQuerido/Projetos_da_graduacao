Segundo programa:
+ senha: tipo str

## Exercício 2.b
### Estruturas identificadas:
Primeiro programa:
    + **Estruturas identificadas**
      - for (interação limitada)
      - if (execução condicional)
    + **Sintaxe**
        - for <variável> in <lista>:
              <comandos>
        - if <condição>:
             <comandos>
Segundo Programa:
    + **Estruturas identificadas**
      - while (interação condicional)
      - if/else (execução condicional)
    + **Sintaxe**
        - for <variável> in <lista>:
              <comandos>
        - if <condição>:
             <comandos>
          else:
             <comandos>
