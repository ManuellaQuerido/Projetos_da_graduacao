# PROJETO LoRa

Este projeto está sendo elaborado pela SmartCampus, setor de tecnologia da prefeitura universitária da UNiversidade Estadual de Campinas (UNICAMP), com o objetivo de obter dados específicos solicitados pela prefeitura. 
Atualmente, o projeto LoRa está em na etapa inicial, sendo que os códigos presentes neste repositório executam apenas uma estimativa de distância até o gateway.
