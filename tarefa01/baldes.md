# Exercício 2.a
Para ser considerado um algoritmo é preciso que a sequência seja finita, ordenada e com instruções bem definidas (não ambíguas), além disso, deve-se ter uma entrada para receber os dados iniciais e uma saída para produzir o resultado quando terminar a sequência. 
O procedimento apresentado não é um algoritmo, pois apresenta um comando ambíguo, ou seja, não é bem definido, já que no comando:
> Despeje **metade** da água do balde A no balde C
o uso do termo *metade* é um comando ambíguo, porque o balde não possui marcação de medida exata e isso impossibilita a execução precisa da instrução

# Exercício 2.b
1. Despeje a água do balde B no balde C até que fique cheio
2. Despeje a água que sobrou do balde B para o balde A até que fique cheio
3. No balde B restará exatamente 1 litro
4. Entregue o balde B
